# Flappy Racoon

A fun and challenging game where you control a raccoon through obstacles while collecting coins. Built with HTML5 Canvas and JavaScript.

## Features

- Multiple character skins
- Different backgrounds
- Coin collection system
- High score tracking
- Sound effects with mute option
- Mobile-friendly
- Responsive design

## How to Play

1. Press spacebar or tap/click to make the raccoon jump
2. Avoid obstacles
3. Collect coins to unlock new characters
4. Try to beat your high score!

## Play Online

You can play the game online at: https://nsbblood.github.io/FlappyRacoon/

## Technologies Used

- HTML5 Canvas
- JavaScript
- CSS3
